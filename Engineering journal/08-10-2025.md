Date: 08/10/2025

Entry:

Today we began programming the wall-following correction algorithms using LiDAR data. During testing, we encountered a power issue where current spikes from the SPIKE controller caused intermittent communication failures with the LiDAR. We implemented temporary fixes including software current limiting and added capacitors to stabilize the power supply while we develop a more permanent hardware solution.

Fecha: 10/08/2025

Registro:

Hoy comenzamos a programar los algoritmos de corrección para el seguimiento de paredes usando datos del LiDAR. Durante las pruebas, apareció un problema de energía donde picos de corriente del controlador SPIKE causaban fallos intermitentes en la comunicación con el LiDAR. Implementamos soluciones temporales incluyendo limitación de corriente por software y agregamos capacitores para estabilizar la alimentación, mientras desarrollamos una solución hardware más permanente.
